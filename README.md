# Dashboard de Controle de FIIs

Este arquivo HTML constitui a interface de um dashboard de controle de fundos imobiliários (FIIs). Seu objetivo é fornecer uma visão consolidada e interativa sobre a posição da carteira, compras, setores, distribuição e momento de investimento.

## Estrutura e Funcionalidades

- **Cabeçalho**: Título, descrição e botões principais, como o de recalcular tudo.
- **Coluna Esquerda**: 
  - **FIIs**: Tabela com informações sobre os ativos, quantidade, preço, valor total, preço médio e posição atual.
  - **Compras**: Tabela para registrar novas compras com dados de data, ativo, quantidade, preço e valor.
- **Coluna Direita**:
  - **Setores**: Distribuição por setor com valores, porcentuais e diferenças.
  - **Aporte**: Planejamento de aportes, com cálculo proporcional baseado na diferença para a meta.
  - **Gráfico de setores**: Representação visual da distribuição atual.
  - **Momento de compra**: Análise rápida de setores com maior potencial de compra.

## Tecnologia Utilizada

- HTML5 para estrutura
- CSS customizado para aparência visual moderna
- Chart.js para gráficos interativos
- JavaScript para lógica de cálculos, eventos e atualização dinâmica

## Objetivo

Facilitar a gestão e análise de carteira de FIIs, permitindo ajustes rápidos e visualização clara do desempenho e estratégias de alocação.

## Como usar

Ao abrir este arquivo em um navegador, o usuário poderá interagir diretamente com as tabelas, ajustar valores, registrar compras, atualizar gráficos e visualizar recomendações de momento de compra.
